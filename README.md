# BlogSpace

A full-stack blog application where users can register, log in, and create, edit, publish, or draft their own blog posts. Anyone can browse published posts; only the author can manage their own.

**Live site:** https://blogapp-komal.onrender.com

## Features

- User registration & login with JWT sessions and bcrypt-hashed passwords
- Create, edit, delete, publish or draft blog posts
- Personal dashboard with post counts and quick edit/delete
- Public home feed with a dedicated page to read each post in full
- Responsive design with mobile navigation menu

## Tech Stack

- **Frontend:** HTML, CSS, vanilla JavaScript
- **Backend:** Node.js, Express
- **Database:** Supabase (Postgres)
- **Auth:** JWT + bcrypt
